Turing Atlas 项目文档

运行与核验

本项目包含独立 Python 实现、固定 UTM 转移表、JavaScript 运行器，以及无框架的静态网页。源代码中的 README.md、docs/architecture.md 和 docs/verification.md 提供完整说明。

npm run check
python3 -m http.server 8000 --directory dist

无需安装第三方包。Node.js 20+、Python 3.10+ 即可运行。GitHub Pages 工作流已包含；在仓库 Settings → Pages 中选择 GitHub Actions 即可部署。

操作说明

图灵机模式直接执行 M。通用图灵机模式每次执行一条真实 δU；「完成 M 的一步」会运行若干 U 微步，并在边界核对目标状态、纸带、磁头和停机结果。回退保留最近 2,000 步；完整运行轨迹可导出为 JSON 或 CSV。

更换模式、载入或重置会开始新的一次执行；关闭网页前请导出需要保留的轨迹。方向键 → 单步；空格播放或暂停。

机器约定

B 为空白。目标程序规则为 [当前状态, 读, 下一状态, 写, 方向]。方向为 L/R/H；H 表示写入并停机，不移动磁头。U 的 S 表示该带磁头不动。状态采用正整数编号，一元编码在状态纸带上。

实现规模与上限

U 固定有 48 个非停机状态、两个停机状态、9 个纸带符号和 3,656 条显式规则。界面限制：1,000 条目标规则、状态编号 1–1,000、256 个输入格、20,000 个编码程序格；每次执行最多 20,000 步。宏步按钮每次最多执行 10,000 微步，未完成时可继续。这些是运行器的资源限制；达到上限不意味着程序不会停机。

测试覆盖

验证完整表与 Python 生成器逐行一致、加法的零操作数、逐位取反、二进制进位、负下标扩展、无规则停机、任意状态编号、回退重放，以及 150 个种子固定的随机目标程序。每个检查的宏步都比较完整目标配置。

开放源码结构

python/utm.py：UTM 定义。web/delta.json：全部 δU。web/engine.js：运行器。web/app.js：交互。tests/：差分验证。.github/workflows/：持续集成与 Pages 部署。
